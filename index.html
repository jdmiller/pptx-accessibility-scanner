ℹ️ About This Tool

This accessibility scanner performs comprehensive WCAG 2.2 Level AA compliance checks:

  • Missing and poor-quality alt text
  • Insufficient color contrast (with font-size awareness)
  • Missing language metadata
  • Table headers and structure
  • Reading order and navigation
  • Auto-advancing slides and animations
  • Scanned images and image-of-text
